# Deep Research Report Template (리포트 템플릿)

선택된 티어에 맞는 구조를 따라 최종 리포트를 작성한다.

---

## 티어 선택 가이드

- **Express**: 핵심 섹션만 (Executive Summary, 주제별 2-3개, Counter-Evidence, Source Registry)
- **Standard**: Full에서 Appendix 제외, 각 섹션 분량 축소
- **Full**: 아래 전체 템플릿 사용

---

```markdown
# [주제] — Deep Research Report

**Date:** YYYY-MM-DD
**Researcher:** Deep Research Agent System
**Tier:** [Express / Standard / Full]
**Research Profile:** [Deep-Narrow / Broad-Survey / Balanced]
**Freshness Priority:** [High-Recency / High-Reliability / Balanced]
**Target Audience:** [Expert / General / Decision-maker]
**Agent Allocation:** [사용된 에이전트 배분 — 예: B×2, A, C, D]
**Total Sources:** [N개] (Accessible: [N] / Unavailable: [N])
**Reliability Breakdown:** A등급 [N] / B등급 [N] / C등급 [N] / D등급 [N] / E등급 [N]
**Claim DB:** [파일 경로]
```

## Claim Database 출력

리포트와 별도로, 수집된 모든 Claim을 구조화된 YAML로 저장한다.

```yaml
# {topic-slug}_claims_v1.yaml
meta:
  topic: "[주제]"
  date: "YYYY-MM-DD"
  tier: "[Express/Standard/Full]"
  total_claims: N
  total_sources: N

claims:
  - id: "C001"
    claim: "[주장 내용]"
    domain: "[health/tech/policy/market/...]"
    sources:
      - author: "[저자/기관]"
        title: "[제목]"
        url: "[URL]"
        reliability: "A"
        year: YYYY
        accessible: true
    counter_claims: ["C012", "C015"]
    confidence: "high"  # high/medium/low
    tags: ["keyword1", "keyword2"]
```

**Claim DB 활용:**
- 같은 도메인의 후속 딥리서치 시 기존 DB 검색하여 중복 수집 방지
- 에이전트에게 기존 Claim 전달 → 신규 소스에 집중
- 블로그 콘텐츠 작성 시 소스 자동 참조
