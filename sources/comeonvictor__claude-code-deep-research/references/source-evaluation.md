# Source Evaluation Framework (소스 평가 프레임워크)

## 신뢰도 등급 체계 (A-E 5단계)

### A등급 (Highest Quality) — 핵심 주장의 근거

| 카테고리 | 예시 |
|---------|-----|
| 피어리뷰 학술 논문 | NEJM, Lancet, Nature, Science, JAMA, BMJ, Cell |
| 체계적 리뷰 / 메타분석 | Cochrane Reviews, PRISMA 기반 메타분석 |
| 정부·국제기구 공식 데이터 | WHO, FDA, CDC, NIH, EMA, EFSA |
| 한국 정부 기관 | 식약처(MFDS), 질병관리청(KDCA), 보건복지부, 통계청(KOSTAT) |
| 국가 통계 기관 | 통계청, BLS, ONS, Eurostat, KOSIS |
| 대학 연구소 공식 보고서 | Harvard, Johns Hopkins, Mayo Clinic |
| 전문 학회 가이드라인 | AHA, ADA, NICE, USPSTF |
| 한국 학술 DB | KCI, RISS |

**Trust Level**: 결정적 근거로 인용 가능
**기준**: 피어리뷰 거침, 방법론 투명, 이해충돌 공개, 재현 가능

---

### B등급 (High Quality) — 보조 인용 가능

| 카테고리 | 예시 |
|---------|-----|
| 주요 통신사 / 품질 저널리즘 | Reuters, AP, NYT, Washington Post, BBC |
| 한국 주요 언론 | 연합뉴스, 한겨레, 경향, 한경, 매경, 조선비즈 |
| 한국 전문 매체 | 바이오스펙테이터, IT조선, 디지털데일리, 더벨 |
| 산업 분석 보고서 | McKinsey, Gartner, Forrester, Deloitte, PwC |
| 공신력 있는 전문 매체 | Nature News, STAT News, Ars Technica |
| 공식 문서·스펙 | ISO, IEEE, W3C, Product docs |
| 임상 가이드라인 | 의학 학회, 전문가 단체 |
| 기업 IR / 공식 발표 | SEC 제출 문서, 공식 프레스 릴리즈 |

**Trust Level**: 강한 근거, 핵심 주장은 A등급으로 보완 권장
**기준**: 편집 과정 존재, 저자 신원 확인 가능

---

### C등급 (Moderate Quality) — 맥락 보충용

| 카테고리 | 예시 |
|---------|-----|
| 전문가 기명 의견 | 해당 분야 교수·연구자의 기명 코멘터리 |
| 컨퍼런스 발표 | 학술/산업 컨퍼런스 |
| 사례 연구 | 문서화된 구현 사례 |
| 저명 뉴스 분석 | NYT, WSJ, BBC 기술 섹션 |
| 산업 분석가 보고서 | 유료 보고서 (방법론 포함) |

**Trust Level**: 맥락 제공용, 핵심 주장 단독 근거 불가
**기준**: 전문가 자격, 잠재적 편향 확인

---

### D등급 (Lower Quality) — 리드/보조 참고만

| 카테고리 | 예시 |
|---------|-----|
| 프리프린트 | arXiv, medRxiv, bioRxiv (피어리뷰 미완료 명시 필수) |
| 전문가 블로그 | 해당 분야 전문가의 개인 블로그 |
| 컨퍼런스 초록 | 예비 발견 |
| 프레스 릴리즈 | 기업 발표 |
| 업계 뉴스 사이트 | 산업 뉴스 매체 |

**Trust Level**: 리드로만 사용, 인용 전 상위 등급으로 검증
**기준**: 상위 등급 소스로 교차 확인

---

### E등급 (Use with Caution) — 인용 금지, 맥락 메모만

| 카테고리 | 예시 |
|---------|-----|
| 익명 소스 | 검증 불가 주장 |
| 근거 없는 의견 | 추측, 감정적 주장 |
| 오래된 정보 | 빠르게 변하는 분야에서 3년+ |
| 명백한 편향 | 벤더 마케팅, 옹호 사이트 |
| 소셜 미디어 | Twitter/X, Reddit, Facebook |
| AI 생성 콘텐츠 | 검증 안 된 LLM 출력 |
| 광고성 콘텐츠 | Sponsored, Advertorial |

**Trust Level**: 근거로 인용 금지
**기준**: 대안 소스 없을 때만, 불확실성 플래그 필수

---

## 자동 등급 하락 조건

| 조건 | 조치 |
|------|------|
| 저자 없음 | → E |
| 날짜 없음 | → 2단계 하락 |
| 깨진 인용 | → 1단계 하락 |
| 철회된 논문 | → E |
| 약탈적 저널 | → E |
| SEO 콘텐츠 팜 | → E |
| 순환 인용 | → 조사 필요 |

## 소스 평가 체크리스트

1. **저자 전문성**: 해당 분야 자격/경력이 있는가?
2. **발행 매체**: 편집·검증 절차가 있는 매체인가?
3. **방법론 투명성**: 데이터 수집/분석 방법이 공개되어 있는가?
4. **이해충돌**: 자금 출처나 이해관계가 공개되어 있는가?
5. **발행 시점**: 해당 주제에서 최신 정보인가?
6. **인용 빈도**: 다른 신뢰할 만한 소스에서 인용되고 있는가?
7. **재현 가능성**: 독립적으로 검증할 수 있는 정보인가?

## Freshness vs Reliability 가중치 매트릭스

| Profile | A가중 | B가중 | C가중 | D가중 | E가중 | 최근2년 | 5년+ |
|---------|------|------|------|------|------|--------|------|
| High-Recency | 1.2x | 1.0x | 0.8x | 0.5x | 0x | +1.5x | -0.5x |
| High-Reliability | 2.0x | 1.0x | 0.5x | 0.3x | 0x | +1.0x | 없음 |
| Balanced | 1.5x | 1.0x | 0.7x | 0.4x | 0x | +1.2x | -0.3x |

## URL 접근성 검증

Phase 3에서 수집된 모든 URL에 대해 WebFetch로 확인한다.

| 상태 | 태그 | 처리 방법 |
|------|------|---------|
| 정상 접근 | `[Accessible]` | 그대로 사용 |
| 페이월/로그인 | `[Paywall]` | 출처 유지, 태그 표시 |
| 404/삭제됨 | `[URL unavailable]` | archive.org 검색 → 실패 시 태그 |
| 지역 제한 | `[Geo-restricted]` | 출처 유지, 태그 표시 |

**임계값 경고:**
- 전체 URL 접근 불가 30%+ → Phase 3.5 보충 리서치 트리거 + "소스 접근성 경고" 명시
- 핵심 주장 소스 접근 불가 → 대체 소스 확보 필수, 실패 시 confidence 하향

## 교차 검증 규칙

1. **핵심 주장(Core)**: A등급 2개+ 또는 B등급 3개+ 필요
2. **보조 주장(Supporting)**: A등급 1개 또는 B등급 2개+
3. **탐색적 주장(Exploratory)**: B등급 1개+ + "추가 연구 필요" 표시
4. **단독 소스 주장**: "단독 소스 기반" 경고 표시 필수
5. **상충 정보**: 양측 소스 등급과 근거 강도를 비교 분석하여 제시

## 도메인별 조정

### 기술/AI
- 프리프린트 수용 가능 (분야 속도 빠름)
- 기업 연구 블로그 (Google AI, OpenAI) 품질 인정
- GitHub 레포 = 코드 관련 1차 소스
- 벤치마크 논문 필수 (성능 주장 시)

### 의학/건강
- 피어리뷰 필수 (건강 관련 주장)
- 임상시험 등록 확인 필수
- FDA/규제 승인 상태 검증 필수
- 환자 집단과 샘플 크기 중요

### 비즈니스/시장
- 시장 규모 주장에 방법론 필수
- 기업 재무: SEC 제출 = A등급
- 프레스 보도만으로 불충분

### 법률/정책
- 1차 법률/규정 = A등급
- 법원 문서/판결 = A등급
- 로펌 분석 = B등급
- 뉴스 보도 = C등급
