# Output Templates Reference

Templates for different research output formats. Read this when generating final reports.

---

## Standard Report Template

```markdown
# {TOPIC} — Deep Research Report

> **Research Date:** {YYYY-MM-DD}
> **Mode:** {Quick | Standard | Deep | UltraDeep}
> **Sources Analyzed:** {TOTAL} (Tier 1: {N1} | Tier 2: {N2} | Tier 3: {N3} | Discarded: {ND})
> **Citation Chains Explored:** {N_CHAINS} chains, up to {DEPTH} levels deep
> **Overall Evidence Confidence:** {HIGH | STRONG | MODERATE | MIXED}

---

## Executive Summary

{3-5 sentences capturing the most important findings. Lead with the single most
actionable or surprising insight. Write for someone who will only read this section.}

---

## Key Findings

### 1. {Finding Title}

{Detailed explanation of the finding with evidence citations [1], [2], [3].
Include direct quotes from primary sources where they add value.
Structure as: claim -> evidence -> implication.}

**Evidence Confidence:** {Verified | Strong | Moderate | Emerging | Contested}
**Primary Sources:** [{source numbers}]
**Triangulation:** {N} independent sources agree | {describe any dissent}

---

### 2. {Finding Title}

{Same structure as above}

---

### N. {Finding Title}

{Continue for all major findings}

---

## Comparative Analysis

{Only include if the research involves comparing alternatives.}

| Criterion | Option A | Option B | Option C | Evidence |
|-----------|----------|----------|----------|----------|
| {criterion 1} | {assessment} | {assessment} | {assessment} | [{sources}] |
| {criterion 2} | ... | ... | ... | ... |

**Recommendation:** {If appropriate, state which option the evidence supports and why}

---

## Practical Implications

{What these findings mean in practice. Organized as actionable bullet points:}

- **For {context/role 1}:** {specific implication}
- **For {context/role 2}:** {specific implication}
- **Immediate actions:** {what to do now based on findings}

---

## Limitations & Knowledge Gaps

### What This Research Could Not Answer
{Be specific about gaps — these are often the most valuable part of the report}

- {Gap 1}: {why it couldn't be answered and what would be needed}
- {Gap 2}: ...

### Methodological Limitations
- Web search coverage: {what sources couldn't be accessed}
- Recency bias: {note if most sources are very recent}
- Language bias: {note if research was limited to English sources}

---

## Future Directions & Emerging Trends

{Based on the evidence, what's coming next in this space:}

1. **{Trend 1}:** {evidence and timeline}
2. **{Trend 2}:** {evidence and timeline}

---

## Research Methodology

This report was produced using the deep-research skill v1.0:

- **Query decomposition:** {N} sub-questions across {M} perspective categories
- **Agent deployment:** {N_AGENTS} specialized agents in {N_WAVES} research waves
- **Source evaluation:** 6-dimension credibility scoring (authority, freshness, relevance, evidence quality, peer validation, independence)
- **Citation chasing:** {backward/forward} chasing up to {DEPTH} levels, expanding source base by {EXPANSION_PCT}%
- **Evidence triangulation:** Major claims verified across {MIN_SOURCES}+ independent sources
- **Quality assurance:** Automated red-team review checking hallucination, citation integrity, bias, coverage, and logical consistency
```

## Quick Mode Report Template

For Quick mode, use a compressed format:

```markdown
# {TOPIC} — Quick Research Summary

> Sources: {N} | Date: {YYYY-MM-DD} | Confidence: {level}

## Summary
{5-8 sentences covering the key findings}

## Key Points
1. {Point 1} [{source}]
2. {Point 2} [{source}]
3. {Point 3} [{source}]
4. {Point 4} [{source}]
5. {Point 5} [{source}]

## Sources
1. {Author}. "{Title}". {Source}, {Year}. {URL}
...
```

## Evidence Object Schema

Each source collected by research agents follows this schema:

```yaml
evidence_object:
  source_url: string          # Full URL
  source_title: string        # Page/paper title
  source_type: enum           # academic|industry|documentation|community|news|video
  source_date: string         # YYYY-MM-DD or YYYY-MM or YYYY
  author: string              # Author name(s), "Unknown" if not identifiable
  key_findings:               # 2-5 bullet points
    - string
  direct_quotes:              # 1-3 verbatim quotes
    - quote: string
      context: string
  relevance_to_question: list # Which sub-question(s) this addresses
  cited_sources:              # Sources this source cites (for backward chasing)
    - title: string
      author: string
      year: string
  credibility_signals:
    domain_authority: enum    # high|medium|low|unknown
    author_credentials: enum  # yes|partial|no
    peer_reviewed: enum       # yes|no|n-a
    recency: integer          # Publication year
    citation_count: string    # Number or "unknown"
    cross_referenced: enum    # yes|partial|no
  credibility_score:
    authority: float          # 0.0-1.0
    freshness: float
    relevance: float
    evidence_quality: float
    peer_validation: float
    independence: float
    composite: float          # Weighted composite score
  tier: enum                  # tier1|tier2|tier3|discard
  citation_chain: string      # How this source was found (search|backward_chase|forward_chase)
```
