# Deep Research

AI-powered deep research agent that automates multi-source research, synthesis, and report generation.

## What it does

Give it a research question, and it will:

1. **Plan** — decompose the question into researchable sub-queries
2. **Search** — run multi-source web searches (APIs, engines, datasets)
3. **Read** — fetch, clean, and extract relevant content from sources
4. **Synthesize** — cross-reference findings, resolve contradictions, identify gaps
5. **Report** — generate a structured, cited research report
